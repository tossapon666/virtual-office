# Virtual Office — ออฟฟิศเสมือนที่มีทีม AI ทำงานแทนคุณ

เว็บแอปสำหรับเจ้าของกิจการคนเดียว ที่มี “พนักงาน AI” ประจำแต่ละแผนกคอยดูแลงาน เอกสาร ปฏิทิน และสรุปภาพรวมให้ โดยคุณเป็นคนสั่งการเพียงคนเดียว

## เริ่มใช้งาน

1. ดับเบิลคลิก `run.bat`
2. เปิดเบราว์เซอร์ที่ http://localhost:5100 (สคริปต์จะเปิดให้อัตโนมัติ)
3. เข้าสู่ระบบครั้งแรก
   - ผู้ใช้: `admin`
   - รหัสผ่าน: `admin123`
4. เปลี่ยนรหัสผ่านได้ที่เมนูโปรไฟล์ (มุมขวาบน) → เปลี่ยนรหัสผ่าน

> ต้องมี Python 3.10 ขึ้นไป และ Flask (สคริปต์ติดตั้งให้อัตโนมัติ)

## สิ่งที่ทำได้ในเวอร์ชันนี้

- **ออฟฟิศเสมือน** — แยกห้องตามแผนก มีตัวละครนั่งทำงาน คลิกห้องเพื่อดูข้อมูลแผนก คลิกตัวละครเพื่อคุยกับผู้ช่วย
- **สั่งงานด้วยภาษาธรรมชาติ** — ช่องสั่งงานบนหน้าแรก (กด `Ctrl`+`K` เพื่อโฟกัส) พิมพ์ภาษาไทยแล้วระบบสร้าง/ปิด/เลื่อนงานให้ทันที
- **ทีม AI 6 คน** — เลขาธิการส่วนตัว, นักบัญชี, เจ้าหน้าที่เอกสาร, ผู้ดูแลคลังเอกสาร, ธุรการปฏิบัติการ, เจ้าหน้าที่สต็อก
- **งานและแจ้งเตือน** — เพิ่ม/แก้ไข/ปิดงาน กำหนดผู้รับผิดชอบ วันส่ง ความสำคัญ งานซ้ำ และติดตามงานเกินกำหนด
- **แจ้งเตือนอัตโนมัติ** — ทีม AI ตรวจงานทุกครั้งที่เปิดใช้งาน และทุก 45 วินาที สร้างแจ้งเตือนงานใกล้ถึงกำหนด/เกินกำหนด/สรุปประจำวัน
- **ปฏิทิน** — ดูงานรายเดือน คลิกวันเพื่อดูและเพิ่มงาน
- **ศูนย์เอกสาร** — อัปโหลด ลากไฟล์มาวาง จัดหมวด แยกแผนก ค้นหา ดาวน์โหลด และลบ
- **แดชบอร์ดปรับแต่งได้** — เพิ่ม/ซ่อน/ลากจัดลำดับ/สลับขนาดการ์ด และบันทึกอัตโนมัติ
- **แชทกับผู้ช่วย** — สั่งงานหรือคุยในแชทได้เลย ใช้ข้อมูลจริงในระบบสรุปงาน และต่อ AI จริงเพื่อคุยลึกขึ้น
- **PWA** — ติดตั้งบนมือถือ/เดสก์ท็อปผ่านเบราว์เซอร์ และเปิดใช้ได้ทุกที่เมื่อ deploy ขึ้นออนไลน์
- **สำรองข้อมูล** — เมนูโปรไฟล์ → สำรองข้อมูล (JSON)

## สั่งงานด้วยภาษาธรรมชาติ

พิมพ์สั่งงานที่ช่องบนหน้า “ออฟฟิศเสมือน” หรือกด `Ctrl` + `K` เพื่อโฟกัสช่องสั่งงานทันที (ใช้ได้ทั้งในแชทกับผู้ช่วยแต่ละคน) ระบบเข้าใจภาษาไทยแบบไม่ต้องเรียนคำสั่ง ทำงานได้ทันทีโดยไม่ต้องตั้งค่า AI ภายนอก

| ต้องการ | ตัวอย่างที่พิมพ์ได้ |
| --- | --- |
| เพิ่มงาน | `เพิ่มงาน ตรวจสต็อกพรุ่งนี้ 10:00 ให้พี่บี` |
| เพิ่มงานด่วน/ทำซ้ำ | `เพิ่มงาน ประชุมทีมวันจันทร์ บ่าย 2 ด่วนมาก` · `ส่งรายงานภาษีวันที่ 20 ทุกเดือน` |
| ปิดงาน | `ปิดงาน ตรวจรายจ่ายพนักงาน` |
| เลื่อนกำหนด | `เลื่อนงาน ปิดบัญชีประจำเดือน ไปวันที่ 20` |
| ค้นเอกสาร | `หาเอกสาร สัญญาลูกค้า A` |
| ดูภาพรวม | `สรุปงานวันนี้` · `งานไหนด่วนที่สุด` |
| ดูคำสั่งทั้งหมด | `ช่วยอะไรได้บ้าง` |

สิ่งที่ระบบอ่านให้อัตโนมัติ:

- **วันที่** — วันนี้ / พรุ่งนี้ / มะรืน / อีก 3 วัน / วันจันทร์ / วันที่ 20 / 20 พ.ย. / สิ้นเดือน / เดือนหน้า
- **เวลา** — 10:00 / บ่าย 2 / 4 โมงเย็น / ทุ่ม / เที่ยง
- **ความสำคัญ** — ด่วนมาก / ด่วน / ไม่เร่ง
- **งานซ้ำ** — ทุกวัน / ทุกสัปดาห์ / ทุกเดือน / ทุกปี
- **ผู้ช่วยและแผนก** — ระบุชื่อ (เช่น `ให้พี่บี`) หรือบทบาท (เช่น `ฝ่ายบัญชี`) ถ้าไม่ระบุ ระบบจะเลือกผู้ช่วยที่เหมาะสมให้อัตโนมัติ

ถ้าชื่องานใกล้เคียงกันหลายงาน ระบบจะแสดงปุ่มให้เลือกแทนการเดา และเมื่อสั่งสำเร็จจะเห็นผลทันทีทั้งในหน้าแรก รายการงาน และแดชบอร์ด

## เปิดโหมด AI จริง (ไม่บังคับ)

ระบบทำงานได้เต็มที่โดยไม่ใช้ AI ภายนอก แต่ถ้าต้องการให้ผู้ช่วยคุยฉลาดขึ้น ตั้งค่า environment variables ก่อนรัน:

```powershell
$env:AI_API_KEY="your-api-key"
$env:AI_BASE_URL="https://api.openai.com/v1"   # หรือ endpoint ที่เข้ากันได้กับ OpenAI
$env:AI_MODEL="gpt-4o-mini"
.\run.bat
```

หรือสร้างไฟล์ `set-ai.bat` ไว้ข้าง `run.bat`:

```bat
set AI_API_KEY=your-api-key
set AI_MODEL=gpt-4o-mini
```

เมื่อตั้งค่าแล้ว ป้ายในหน้าผู้ช่วยจะแสดง “AI จริง” แทน “โหมดอัตโนมัติ” และหากเรียก API ไม่สำเร็จ ระบบจะกลับไปตอบด้วยข้อมูลจริงในฐานข้อมูลให้เอง

ในโหมด AI จริง ผู้ช่วยสามารถเรียกเครื่องมือของระบบได้เอง (function calling) เช่น สร้างงาน ปิดงาน เลื่อนกำหนด ดูรายการงาน และค้นเอกสาร ดังนั้นพิมพ์สั่งแบบธรรมชาติได้เลย แล้ว AI จะตัดสินใจเรียกเครื่องมือที่เหมาะสม พร้อมสรุปผลกลับมาเป็นภาษาไทย

## เปลี่ยนรหัสผ่าน / ความปลอดภัย

- รหัสผ่านถูกเก็บเป็น hash (werkzeug) ไม่ได้เก็บเป็นข้อความธรรมดา
- session อายุ 30 วัน และคุกกี้เป็น HttpOnly + SameSite=Lax
- ไฟล์อัปโหลดถูกจำกัดประเภทและขนาด 25 MB
- แนะนำให้ตั้ง `OFFICE_PASSWORD` ก่อนรันครั้งแรกเพื่อไม่ใช้รหัสเริ่มต้น:
  ```powershell
  $env:OFFICE_PASSWORD="รหัสของคุณ"
  ```

## ข้อมูลเก็บที่ไหน

ค่าเริ่มต้น (รันในเครื่อง):
- ฐานข้อมูล: `office.db` (SQLite)
- ไฟล์แนบ: โฟลเดอร์ `uploads/`
- สำรองข้อมูล: คัดลอกทั้งสองรายการ หรือใช้เมนู “สำรองข้อมูล (JSON)”

เมื่อออนไลน์ (แนะนำ):
- **ฐานข้อมูล → Turso** ตั้ง `TURSO_DATABASE_URL` + `TURSO_AUTH_TOKEN` แล้วแอปจะใช้ libSQL แทน `office.db` อัตโนมัติ
- **ไฟล์แนบ → Google Drive** ตั้งค่าที่เมนู **🗄️ ที่เก็บข้อมูล** (service account JSON + Folder ID)
- ดูขั้นตอนทั้งหมดใน [`DEPLOY_OPTIONS.md`](DEPLOY_OPTIONS.md)
- ตรวจสถานะได้ที่ `GET /api/system/status` หรือดู badge ในเมนู **🗄️ ที่เก็บข้อมูล**

## ขึ้นออนไลน์ให้ใช้ได้ทุกที่

ตัวเลือกที่ง่ายที่สุดคือรันในเครื่อง/เซิร์ฟเวอร์ แล้วเปิดผ่าน Cloudflare Tunnel:

```powershell
cloudflared tunnel --url http://localhost:5100
```

จะได้ URL แบบ `https://....trycloudflare.com` ใช้เปิดจากมือถือได้ทันที (เหมาะสำหรับทดลอง)

สำหรับใช้งานจริงระยะยาว แนะนำ:
- **Render free + Turso (DB) + Google Drive (ไฟล์) + keep-alive ping** — ดู [`DEPLOY_OPTIONS.md`](DEPLOY_OPTIONS.md)
- VPS ขนาดเล็ก + systemd/NSSM รัน `app.py` หลัง reverse proxy (Caddy/Nginx) + HTTPS
- หรือแพลตฟอร์มที่มี persistent disk เช่น Railway/Render/Fly.io
- ฐานข้อมูล SQLite เหมาะกับผู้ใช้คนเดียว/ทีมเล็ก หากต้องการหลายเครื่องพร้อมกันมาก ๆ ค่อยย้ายไป Postgres

## โครงสร้างโปรเจกต์

```
virtual-office/
├─ app.py            # Flask routes + REST API
├─ db.py             # schema + Turso/libSQL adapter + ข้อมูลตั้งต้น
├─ agents.py         # สมองทีม AI / แจ้งเตือน / แชท / ตัวแยกคำสั่งภาษาไทย
├─ tools/
│  └─ migrate_to_turso.py   # ย้าย SQLite → Turso (ครั้งเดียว)
├─ .github/workflows/keepalive.yml  # ping กัน Render sleep
├─ templates/
│  ├─ index.html
│  └─ login.html
├─ static/
│  ├─ app.css, login.css
│  ├─ js/ (core, views, dashboard, modals, agent, events)
│  ├─ manifest.webmanifest, sw.js, icon*
├─ uploads/          # ไฟล์แนบ (สร้างอัตโนมัติ / สำเนา cache)
├─ office.db         # ฐานข้อมูล (สร้างอัตโนมัติเมื่อไม่ใช้ Turso)
└─ run.bat
```

## แนวทางต่อยอด

- เพิ่มแผนก/ผู้ช่วยใหม่ผ่านฐานข้อมูลหรือหน้าแอดมิน
- เชื่อมปฏิทินภายนอก (Google Calendar) และอีเมลแจ้งเตือน
- ให้ AI อ่านเนื้อหาไฟล์ PDF/Word แล้วสรุปอัตโนมัติ
- ระบบสิทธิ์หลายผู้ใช้ (ตอนนี้ตั้งใจให้เจ้าของคนเดียวควบคุมทีม AI)
- มุมมองออฟฟิศแบบ isometric เต็มรูปแบบ พร้อมแอนิเมชันตัวละครเดินไปมา
